# Architecture decision records

One file per decision that a newcomer would otherwise question.

- Name: `YYYY-MM-DD-short-slug.md` (dates avoid number clashes when several
  people add decisions at the same time).
- Copy `_template.md`. Keep it under a page.
- A decision is never edited after it is accepted. To change it, write a new
  one and set the old one's status to `superseded by <file>`.

| File | Decision |
| --- | --- |
| `2026-11-18-adopt-living-spec-sdd.md` | Use living-spec SDD as the development method |
